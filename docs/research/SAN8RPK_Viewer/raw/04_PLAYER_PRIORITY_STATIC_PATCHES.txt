ai_patch.AIController._patch_bytes()
------------------------------------

Equivalent behavior reconstructed from Python 3.10 bytecode:

static = getattr(self.profile, "STATIC_PATCHES", {})
if offset in static:
    return static[offset]

if hasattr(self.profile, "replacement"):
    return self.profile.replacement(offset)

return self.profile.make_jump(self.cave + offset)

Therefore -1/-2 are static replacement keys, not cave offsets.

AIController._exchange()
------------------------

Iterates profile.HOOKS:

for rva, original, offset in profile.HOOKS:
    jump = self._patch_bytes(offset)
    if enabling:
        before, after = original, jump
    else:
        before, after = jump, original

Then:
- verify current bytes == before
- VirtualProtectEx
- WriteProcessMemory
- FlushInstructionCache
- verify current bytes == after
- rollback touched changes on failure
- restore original bytes on disable
