# 04. 기술도시 — 게임 내 도시 편집기 노출

## CT에서 확인된 동작

대상 항목은 `도시 편집 - 기술도시 인 게임 편집기 표시 (종합편집기 켜지면 그 쪽 우선)`이다.

- 검증 시작 주소: `SAN8RPK.exe+12CA4F1`
- 원본 bytes: `40 80 FF 03 74 50 0F B6 CB E8 C1 FA 4E 00`
- 실제 수정 위치: `SAN8RPK.exe+12CA4F5`
- 원본 분기: `74 50`
- 활성화 패치: `90 90`

즉, `cmp dil,03` 뒤의 `je +0x50` 분기를 NOP 처리하여 **city feature ID 3을 명시적으로 건너뛰는 로직만 제거**한다.

CT 주석에는 다음이 명시되어 있다.

- SAN8RPK.exe 실행 코드 기준 2026-09-30 확인.
- 도시 편집기를 닫은 상태에서 toggle 후 다시 열 것.
- UI에서 선택/저장/재로드까지는 아직 게임 내 테스트되지 않음.
- 종합 편집기가 켜지면 그쪽을 우선 사용한다는 운용 메모가 있음.

## 현재 코드와의 관계

현재 프로젝트에는 `Bigcityconvert.cpp`가 있으며, 이는 특정 도시를 **기술도시 타입으로 전환하고 최대 수치까지 변경**하는 기능이다. 이번 CT 기능은 도시 타입 자체를 변경하지 않고 **게임 내 도시 편집기에서 기술도시 항목을 숨기는 분기를 제거**하는 기능이다.

따라서 두 기능은 이름이 비슷해도 목적이 다르다.

- 기존 기능: 도시 데이터를 기술도시로 변환.
- 이번 기능: 이미 기술도시인 항목을 게임 내 편집 UI에 노출.

현재 `CityInfoWindow.cpp`의 자체 종합 도시 관리/편집 UI와도 별개다. 이 CT는 게임 원본의 도시 편집 화면을 대상으로 한다.

## C++ 치트 적용안

### 상태/UI

- 단일 bool toggle.
- 제안 이름: `게임 내 도시 편집기에 기술도시 표시`.
- 설명에 `도시 편집기를 닫고 전환 후 다시 열기`를 명시한다.
- 자체 종합 도시 편집 UI가 열려 있을 때 기능 자체를 막을 필요는 없지만, 사용자가 혼동하지 않도록 "종합 편집기 사용 시 그쪽 우선" 안내를 유지한다.

### 패치

- enable 전 `+12CA4F1`의 전체 14-byte 시그니처를 검증한다.
- 실제 쓰기는 `+12CA4F5`의 2 bytes만 `74 50 -> 90 90`으로 변경한다.
- disable 시 현재값이 `90 90`일 때만 `74 50`으로 복구한다.
- 다른 패치가 해당 분기를 변경한 경우 원복/적용을 거부한다.
- 코드 섹션 변경이므로 `PAGE_EXECUTE_READWRITE`와 `FlushInstructionCache`를 사용한다.

이 기능은 code cave가 필요 없다.

## 적용 우선순위

구현 난도는 낮지만, CT 자체가 저장/재로드를 아직 검증하지 않았다고 명시하므로 **기능 추가 후 반드시 게임 내 검증을 거쳐야 하는 항목**이다.

## 구현 전/후 확인 항목

1. 원본 상태에서 기술도시(feature ID 3)가 게임 내 도시 편집기에서 제외되는지 확인.
2. toggle ON 후 편집기를 다시 열었을 때 기술도시 항목이 표시되는지 확인.
3. 해당 항목 선택이 정상 동작하는지 확인.
4. 값을 수정하고 저장했을 때 실제 도시 데이터에 반영되는지 확인.
5. 편집 화면을 닫고 다시 열어 값이 유지되는지 확인.
6. 세이브/로드 후에도 값이 예상대로 유지되는지 확인.
7. 기존 `기술도시로 전환` 기능과 함께 사용할 때 데이터 손상이나 UI 충돌이 없는지 확인.
8. 자체 `도시 관리`/종합 편집 UI와 함께 사용할 때 단순 중복 UI인지, 상태 불일치가 생기는지 확인.
9. toggle OFF 후 원본 분기와 원래 숨김 동작이 복구되는지 확인.

## 미확인 사항

- feature ID 3의 정식 내부 명칭은 CT 주석의 기술도시 설명에 기반한다.
- 게임 원본 편집기의 저장 루틴이 feature ID 3을 완전히 지원하는지는 CT에서 확인되지 않았다.
- 실제 게임 런타임 검증은 이번 문서화 작업에서 수행하지 않았다.
